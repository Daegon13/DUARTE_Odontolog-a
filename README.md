# DUARTE_Odontología — Demo privada

Demo comercial conceptual no oficial para la Dra. Clara Duarte, Montevideo.

## Privacidad / indexación
- `meta robots`: `noindex,nofollow,noarchive,nosnippet`
- `meta googlebot`: `noindex,nofollow,noarchive,nosnippet`
- Aviso visible de propuesta conceptual no oficial.
- `robots.txt` bloquea todo rastreo.
- `_headers` y `vercel.json` añaden `X-Robots-Tag` para despliegues compatibles.

> Para una demo publicada en un servidor real, se recomienda además proteger la URL con contraseña o autenticación HTTP y, como capa adicional, enviar `X-Robots-Tag: noindex, nofollow` desde el servidor.
